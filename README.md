# Minerux Apocalypse Launcher

Launcher de Windows para **Minerux Apocalypse — The Fallen World**.

> **Estado: en desarrollo.** No existe todavía una versión de Windows validada para jugadores. No descargar ejecutables no verificados como si fueran versiones finales.

## Objetivo

- Instalación y actualización del cliente Minecraft Java con NeoForge y mods autorizados.
- Inicio de sesión oficial de Microsoft (sin solicitar contraseñas en el launcher).
- Botón **Instalar / Jugar**, progreso de descargas y respuesta fluida de la interfaz.
- Conexión directa al servidor Minerux Apocalypse, sin mostrar su dirección numérica en la interfaz.
- Distribución de versiones comprobadas mediante GitHub Releases.

## Seguridad y distribución

- No almacenar tokens ni contraseñas en este repositorio.
- Comprobar licencias antes de redistribuir mods de terceros.
- Verificar versiones, integridad de archivos y compatibilidad de Minecraft/NeoForge antes de publicar.
- La compatibilidad Bedrock requiere una solución independiente: Bedrock no ejecuta mods Java NeoForge.

## Publicaciones

La sección **Releases** se utilizará cuando exista un instalador compilado y probado en Windows. Por ahora **no hay un instalador final publicado**.
